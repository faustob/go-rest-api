# Instrumentation for Go-rest-api

Generated by TelemetryOS for the agreed SLO contract (v1). This PR adds the
OpenTelemetry instrumentation needed to emit the SLIs selected below.

## SLIs implemented
- **Go-rest-api — HTTP Service Availability** (`go-rest-api-http-availability`) — target 99.95% over 30-day
- **Go-rest-api — HTTP Response Time P95** (`go-rest-api-http-latency-p95`) — target < 200ms over 1-hour
- **Go-rest-api — HTTP Response Time P99** (`go-rest-api-http-latency-p99`) — target < 750ms over 1-hour
- **Go-rest-api — HTTP 5xx Error Rate** (`go-rest-api-http-error-rate`) — target < 0.1% over 1-hour
- **Go-rest-api — Authentication Failure Rate** (`go-rest-api-http-auth-failure-rate`) — target < 2% over 1-hour
- **Go-rest-api — HTTP Request Throughput** (`go-rest-api-http-request-rate`) — target baseline ± 30% over 5-minute

## Dependencies
Auto-instrumentation packages referenced by these SLIs:

```sh
npm install go.opentelemetry.io/contrib/instrumentation/net/http/otelhttp go.opentelemetry.io/otel
```

```sh
# Add to your build (Maven/Gradle):

```
```sh
pip install go.opentelemetry.io/contrib/instrumentation/net/http/otelhttp go.opentelemetry.io/otel
```
